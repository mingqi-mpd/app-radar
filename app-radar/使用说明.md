# App Radar

美区 iPhone 免费榜：Games、Finance、Shopping、Casino、Sports、Social Networking、Utilities、Entertainment，每类 Top 100。Casino 为游戏子分类；Sports 使用体育应用榜（不是体育游戏子榜）。

打开「今日榜单.md」查看最新采集摘要；团队使用公开英文网页查看新上榜名单、开发商、商店链接、分类和排名。同一 App 在多个分类符合规则时合并为一条线索。

规则：App 今天出现在任一监控分类，并且前 30 个日历日的已记录数据中没有出现过同一 App ID。8 个分类合并比较，换分类不会重新成为新线索。尚未开始记录的更早日期按空记录处理；新上榜不等于首次发布，也不能证明每日采样以外的时段从未上榜。

每天以 Europe/Rome 日期运行，只保留最近 30 个日历日的 App ID。重复运行不会覆盖同日成功结果。当天必须完整抓取 8 个榜单才发布新线索；部分失败时不发布线索，但已成功观察到的 App ID 仍进入滚动窗口。数据源是 Apple 公开 RSS 分类榜；当前校验每榜 100 个唯一 ID、免费价格、分类标题及来源更新时间（不超过 36 小时）。

新的滚动记录从 2026-09-28 开始。当天是基线，不显示新线索；2026-09-29 起直接与 2026-09-28 比较。App 连续 30 天没有被记录后，再次上榜时可以重新成为线索。

手动运行（Python 3.9 或以上，无额外依赖）：

```sh
python3 radar.py
```

验证筛选逻辑：

```sh
python3 -m unittest discover -s . -p 'test_*.py'
```

每天由 GitHub Actions（.github/workflows/daily.yml）在罗马时间约 09:00 自动运行，抓取、更新 rolling-state.json 并提交回仓库、部署到 GitHub Pages，无需本地电脑联网。失败时 GitHub 会发邮件通知，可在 Actions 页面手动 Run workflow 重跑。本版未包含联系人查找、邮件发送或客户跟进状态管理。
